# Glyph source

Every image in this folder comes from **Kenney's Input Prompts, version 1.5A**
(<https://kenney.nl/assets/input-prompts>), released under Creative Commons Zero (CC0).
Crediting Kenney is not required by the licence; it is done here because it is deserved.

The images are copied unmodified (128 px "Double" size) by `tools/build_glyphs.py`, which also
records which pack file is used for each of the game's 24 Xbox-type inputs. The `generic` style
is the Xbox set without Xbox colours, for 8BitDo and other third-party XInput pads.

covers the artwork's copyright only.
